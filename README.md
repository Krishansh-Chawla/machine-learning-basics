# Machine Learning Basics

A collection of beginner-friendly machine learning projects built using **Python** and **Scikit-learn** while learning the fundamentals of Machine Learning.

## Projects

### 1. Study Hours Predictor

**File:** `study_hours.py`

A simple machine learning model that predicts a student's marks based on the number of hours they study.

**Input:**

* Study Hours

**Output:**

* Predicted Marks

**Concept:** Regression

---

### 2. Student Pass Predictor

**File:** `student_pass_predictor.py`

A classification model that predicts whether a student is likely to pass based on their study hours. The model also provides the probability of passing.

**Input:**

* Study Hours

**Output:**

* Pass/Fail Prediction
* Probability of Passing

**Concept:** Classification

---

### 3. House Price Predictor

**File:** `house_price_predictor.py`

A machine learning model that predicts the price of a house based on its size and number of bedrooms.

**Input:**

* House Area (sq. ft.)
* Number of Bedrooms

**Output:**

* Predicted House Price

**Concept:** Regression

---
